🎯 Sobre o Projeto

Este repositório contém um projeto desenvolvido utilizando TypeScript, criado com o objetivo de aplicar e consolidar os conhecimentos adquiridos em sala de aula e em estudos pessoais sobre a linguagem. O foco principal é explorar:

Tipagem estática do TypeScript

Classes, interfaces e generics

Configurações de compilação (tsconfig.json)

Integração com ferramentas do ecossistema JavaScript/Node

Este projeto serve como base para estudos, experimentação e referência em projetos futuros que utilizem TypeScript.

🧠 O que é TypeScript

TypeScript é um superconjunto de JavaScript que adiciona tipagem estática e recursos de linguagens modernas ao JavaScript, o que resulta em:

código mais seguro e previsível

erros detectados em tempo de compilação

melhor experiência de desenvolvimento

TypeScript é amplamente usado em aplicações web modernas, frameworks front-end (como React) e back-end com Node.js.

🚀 Tecnologias e Ferramentas Utilizadas

TypeScript — linguagem principal

Node.js — ambiente de execução (quando aplicável)

npm — gerenciamento de dependências

tsconfig.json — configuração do compilador

Possíveis bibliotecas auxiliares conforme estudo

▶️ Como Executar o Projeto
Pré-requisitos

Você precisa ter instalado em seu sistema:

Node.js (inclui npm)

TypeScript (instalado localmente ou globalmente)

1️⃣ Clonar o Repositório
git clone https://github.com/mauriciomourag/Projeto_TS.git

2️⃣ Acessar a Pasta
cd Projeto_TS

3️⃣ Instalar as Dependências
npm install

4️⃣ Compilar o Código TypeScript
npm run build


Isso converte os arquivos .ts em .js dentro da pasta de saída.

5️⃣ Executar o Projeto
npm start


Após isso o projeto será executado conforme definido no package.json.
